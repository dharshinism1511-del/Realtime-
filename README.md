# 🚖 TaxiPulse — Real-Time Taxi Demand & Mobility Analytics

A real-time analytics dashboard for taxi trip data built with **Flask + Pandas + Chart.js**.

## Tech Stack
- **Frontend**: HTML5, CSS3 (Glassmorphism), JavaScript, Chart.js
- **Backend**: Python, Flask, Pandas, NumPy
- **Dataset**: Auto-generated CSV (5,000 realistic taxi trips)

## Features
- 📊 Real-time KPI dashboard (trips, revenue, avg fare, avg distance)
- ⚡ Simulated live demand per zone (updates every 3 seconds)
- 📈 Interactive charts:
  - Demand by hour of day
  - Demand by pickup zone
  - Payment method split
  - Demand by day of week
- 🔥 Auto-detects "hot zones" with high demand
- 💎 Premium glassmorphism UI with animated gradients
- 📱 Fully responsive layout
